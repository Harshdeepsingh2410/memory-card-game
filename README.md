# Memory Card Matching Game

A fully functional responsive memory card game built with HTML5, CSS3 and vanilla JavaScript.

## Features
- Randomized 16-card deck with 8 matching pairs
- Pair-matching logic and game-state management
- Card-flip animations
- Move counter
- Timer
- Dynamic score calculation
- Best-score storage
- New Game and Play Again controls
- Responsive layout
- No external dependencies

## Run
Open `index.html` directly in a modern browser. No installation is required.
